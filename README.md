# 🛋️ **Furnish.et** – 3D Furniture Showcase

Welcome to **Furnish.et**, an interactive 3D furniture website where users can explore, customize, and interact with furniture models in real-time. Built with modern web technologies, this platform allows users to change the color, lighting, and textures of various furniture pieces to visualize how they would look in different settings. Perfect for interior designers, home decor enthusiasts, or anyone looking to visualize their dream space.

## 🛠️ **Technologies Used**
This project utilizes the following technologies to deliver a rich and immersive experience:

- **HTML**: For structuring the layout of the website.
- **TailwindCSS**: For fast and responsive styling of the website.
- **Three.js**: Powering the 3D models and interactions for furniture visualization.
- **GSAP**: Creating smooth animations and transitions, especially for model interactivity.
- **JavaScript**: For user interactions like changing colors, light intensity, and manipulating 3D models.

---

## 🌟 **Features**

- **Interactive 3D Models**:  
  Rotate and zoom in on 3D models of furniture to view them from various angles.

- **Customizable Colors & Textures**:  
  Change the colors and textures of the furniture pieces in real-time to match your aesthetic preferences.

- **Dynamic Lighting**:  
  Adjust the lighting to see how the furniture looks under various lighting conditions.

- **Smooth Animations**:  
  Experience smooth animations for transitioning between different views, color changes, and lighting adjustments.

## 🚀 **How to Run the Project Locally**

To run **Furnish.et** locally on your machine, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/Young19ermi/Furnish.et.git
    ```

2. **Navigate to the project folder**:
    ```bash
    cd Furnish.et
    ```

3. **Open the `index.html` file** in your browser to view the project.
